# Optional extras

The MCP server itself is the `makehuman-mcp` script at the **repo root**.
Install with `uvx makehuman-mcp` — see the top-level README.

This folder only keeps:

- `socket-bridge/` — drop-in files if you want the `socket` backend (running
  MakeHuman GUI). The default `local` backend does not need them.
- `skills/makehuman-character/` — agent skill for the character workflow.
